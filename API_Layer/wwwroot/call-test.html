Voice & video call test

Test WebRTC calls with SignalR signaling. Use the same conversation ID on both devices.

📋 Data to enter

  • API base URL — Leave empty if this page is at http://localhost:5202/call-test.html. Otherwise use e.g. http://localhost:5202 or https://localhost:7238.
  • JWT token — Get it by logging in: POST /api/Auth/login with body { "phoneNumber": "1234567890", "password": "StrongPassword123###" }. Copy the token from the response and paste it here.
  • Conversation — Paste your JWT, click Load my conversations, then pick one from the dropdown. Or paste a conversation ID (GUID) if you already have it. Both caller and callee must use the same conversation ID. If the list is empty, create a conversation first: POST /api/chat/conversations with { "doctorId": "<guid>" } (as patient) or { "patientId": "<guid>" } (as doctor); you must have an appointment with that user.
